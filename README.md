# lódz Oisterwijk — website

Showcase website voor **lódz**, designermode aan De Lind 24 in Oisterwijk.
Twee pagina's, plain HTML/CSS/JS — geen build stap.

- `index.html` — homepage (video hero, merken, kleding, accessoires, winkel, over)
- `contact.html` — adres, openingstijden, kaart
- `css/style.css` — alle styling
- `js/main.js` — header-gedrag bij scrollen
- `images/` — foto's en logo's

## Lokaal bekijken

Open `index.html` in een browser, of:

```
npx serve .
```

## Live

Gehost via GitHub Pages vanaf de `main` branch.

## Nog te bevestigen met de klant

- Huisnummer, postcode, telefoonnummer en e-mailadres (nu plausibele placeholders)
- Echte kaart in plaats van de schematische placeholder
- Vector-logo (SVG/EPS) van lódz
- Officiële merklogo's uit de brand kits
